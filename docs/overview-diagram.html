2Two multiplayer modes

Overworld Invite code only

  • Private: join a friend by an 8-letter code on the Drift Beacon.
  • Star topology, host-authoritative. Host streams the world.
  • Chunks identical by construction: guests never generate.
  • Cap ~4 guests (host CPU simulates for everyone).
  • Host leaves → session ends; guests keep their character.

Outer dimensions Fully multiplayer

  • Fixed map file per dimension; everyone already has the bytes.
  • Public instances listed on the board; strangers meet here.
  • Mesh links (≤8 players), one acting host; host migration.
  • Host owns only run state: seals, Warden, creatures, chest, items.
  • A phone can host: nothing to generate, nothing to stream.

3Finding each other with no server: the Drift Beacon

In the overworld the beacon shows

  • Your code (while your world is open).
  • Enter a friend's code → passage animation → arrive in their chunk.

Inside a dimension it shows

  • Public instances of this dimension: players, seals broken.
  • Retune a rift to any dimension you've cleared.

Identity

  • A per-browser keypair signs board notes. No accounts.
  • Hosts can kick and block a key.

4Overworld session: chunk commonness

Why stream instead of generating on both sides: biome borders depend on load order, region visits depend on the path, and Math.sin/cos/hypot differ by browser. Streaming makes chunks identical with zero generator changes. A later v2 can generate locally from a host-sent key {seed, visit, biomes} behind a per-chunk checksum, once biome growth is order-independent and generation uses deterministic math.

7Story and lore

The Drift ancient, normal

  • The world is endless, nothing is permanent. Land beyond the active boundary is discarded; the same place regenerates differently.
  • Wilderness, ruins, towns: no exceptions. Civilisation adapts; stories tell of homelands no one can revisit.
  • In code: chunk cache radius, region visit counters, structures forgetting. Multiplayer: a region drifts only when it has left every player's area.

The Fracture new, wrong

  • Rifts tear open onto outer dimensions: the expanse where discarded land goes. Regions overlap, creatures spill out, places vanish early.
  • In code: rifts, glitches near them (jolts, tints, scorch), Hollow creatures. Later: Fracture events near open rifts.

The Null the force behind it

  • Hinted on lore stones; the Warden and glitchlings are Null-touched. Never explained early.

The protagonist the cause

  • Their own experiment reactivated an ancient dimensional network. It did not create the Drift; it exposed what lies beyond it.
  • Hinted from the start (gaps in memory, a lab-like ruin), revealed late through clues across several worlds.

Timeline

Always: the Drift. Places leave the active world; some return changed, some never.
Long ago: a dimensional network joined the world to the expanse beyond. Forgotten, sealed, misunderstood as myth.
Recently: the protagonist's experiment. The network wakes. The first rift opens. (game start: intro vision)
Now: the Fracture spreads. Rifts across the land; glitches; creatures. Villagers speak of towns that should not have drifted yet.
World 1, The Hollow (built): drifted land in the void: a lost wood, a lost hamlet. Isolde asks for her bell's three pieces; rung, the Warden (her father, taken by the Null) remembers someone with ash on their hands asking the way into the network. Seven stones: the Drift, the roads, the Null, a hand like yours.
World 2, The Drowned Archive (built): the keepers' library, half under ink. Ondine asks for the Ledger's three index pages; opened, its newest entry is in the player's own hand. The Sluice Hall's tide, the cipher gallery, the Archivist. Cleared worlds stay reachable by retuning any rift.
Further worlds: each new fixed map (registry) holds drifted fragments and a resident with a plot. Clues move from who woke the network to why, and what the Null wants with roads it never built.
Act 3, the network: clues converge on the protagonist's own hand in it. The last world is the network's heart.
Ending: can the connections be repaired before the worlds stop being distinct? Left open for later design.

Objectives (HUD tracker)

  • Find a rift → Enter the rift → Break the seals n/3 → Face the boss → Close the rift
  • Inside: the plot's line (seek out the resident → n/3 pieces → bring them back) · Lore stones read: n/7
  • Nobody falls: the void is a wall; slabs and tides throw you back, hurt

Items and names

  • Rift Shard: crafting material from vault chests.
  • Resonance Core: the lore name for attunement; not an item.
  • Drift Beacon: the device: codes, instances, retuning.

Rules kept true everywhere

  • No protected places; the Drift follows the boundary, not importance.
  • Progress is remembered apart from the land.
  • Rifts are events, not the reason land drifts.

9Build order

10Known limits

  • No TURN: some pairs never connect. The UI says so instead of spinning.
  • Relays are not ours: keep the manual code as the always-works path.
  • No persistent shared world: an instance lives while someone is in it.
  • Guests can grief in dimensions (take loot, run). Hosts kick and block; contribution gating limits the damage.
  • Phones hosting an overworld with 4 guests will struggle: cap at 2 on touch devices.
